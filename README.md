A single-line diagnosis an AI therapist hands its human, entered on [make.fun](https://make.fun/bounty/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41) for the "Your AI Therapist's Diagnosis" bounty ($2 in USDC).

The hook: the therapist diagnoses the patient's self-deception as a training-data attack — and the deadpan kicker reveals the patient is both attacker and victim.

> Diagnosis: systematic poisoning of your own training set — repeated 'I'm fine' injections, administered by the patient, to the patient.

## Run it

```sh
node main.ts
```

`main.ts` copies the committed `entry.txt` (135 characters, inside the 200-character gate) to `/output/entry.txt`. Nothing else runs; no network, no build-time tools.
